Privacy Policy — Composio Hermes CLI (Kairos)

Effective date: 2026-08-27

This application accesses the following TikTok data, only for the account owner's own account:

  • Basic profile info (open id, avatar, display name)
  • Profile info (bio, verification status)
  • Account statistics (followers, following, likes, video count)
  • Public video list
  • Ability to publish video/photo content on the owner's behalf

Data usage: This data is used by the account owner's personal AI agent (Kairos) to identify content patterns, understand algorithm/reach trends, support narrative and content creation, and generate insights for the owner's own decision-making. Data is not sold, shared, or disclosed to any third party.

Data retention: Data is kept only while this integration is active. It is deleted upon request or when the integration is disconnected.
